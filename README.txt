# 华硕主板 BIOS 下载工具 v2.3.0

> 江苏振远智能科技有限公司 · ASUS Motherboard BIOS Downloader

单文件 Windows 桌面工具：内置**华硕官网全部在售主板目录**（全球站 878 款 + 中国站特供/渠道补录，共 **909 款**）。**三栏浏览器式**界面：左「芯片组」（平台 → 芯片组）→ 中「型号」（平铺 + 实时搜索）→ 右「BIOS 明细 + 选中版本详情」，选中型号即列出全部 BIOS 历史版本，一键下载（进度条 / SHA-256 校验）。

## 技术要点

- **绕过 Akamai 防护**：华硕官网由 Akamai CDN 保护，普通 Python `urllib` / `requests` 直接访问会被 403。本工具使用 `curl_cffi` 的 `impersonate="chrome124"` 模式伪造 Chrome TLS 指纹，可稳定访问官方 API 与下载直链。
- **DNS 自愈**：运营商 / 路由器递归 DNS 偶发无法解析域名（`www.asus.com` / `odinapi.asus.com` / `dlcdnets.asus.com`）时报 curl error 6/28。工具自动改用 DoH（RFC 8484：阿里 `223.5.5.5` → 腾讯 DNSPod `1.12.12.12`）重试；仅 DNS 类错误触发，其余错误路径不变。
- **官方接口**（非爬 HTML，均为官网前端同款 JSON 接口）：
  - `odinapi.asus.com/recent-data/apiv2/SeriesFilter` → 芯片组分类树（65 个芯片组码）
  - `odinapi.asus.com/recent-data/apiv2/SeriesFilterResult?Category=63|64` → 平台全量型号（63=Intel / 64=AMD，单次返回全部）
  - `odinapi.asus.com/recent-data/apiv2/ModelMapping` → 型号 → `pdid` / `pdhashedid` 映射（普通型号 BIOS 查询前必须先转换）
  - `www.asus.com/support/webapi/ProductV2/GetPDBIOS` → 普通型号 BIOS 列表
  - `rog.asus.com/support/webapi/product/GetPDBIOS` → ROG 型号 BIOS 列表
- **目录构建**：SeriesFilter 取芯片组码 → SeriesFilterResult 按 Category 63/64 拉**全量**型号（Intel 579 + AMD 299）→ 用芯片组码做子串匹配归类（长码优先，`B760M` 命中 `B760`）→ Intel / AMD 分桶，归属不到入「其他」；再由中国站 `WebsiteCode=cn` 补录大陆特供/渠道型号。最终 **909 款**（Intel 554 / AMD 289 / 其他 66）。
- **三路径 BIOS 查询**：`AsusApi.get_bios_panel(board)` 自动分流 —— ① prod 型号先全球站（`ModelMapping` 转 hash/pdid → `GetPDBIOS?website=global`），无数据回退中国站（`website=cn`）；② rog 型号走 `rog.asus.com` 专用接口（`RealProductID` 直连，无需 hash）。
- **断点续传**：下载直链支持 `Range` 头（206 / Accept-Ranges）。
- **离线自检**：EXE 支持 `--check`，无 GUI 自检目录接口 / 目录构建 / BIOS 三路径 / 下载直链（结果写 `asus_bios_checker_selftest.log`）。

## 设置

窗口标题右侧「**设置**」按钮打开设置面板，分三个区段：

| 区段 | 选项 | 默认 |
|---|---|---|
| ① 更新检测 | 目录自动刷新间隔（下拉） + 「立即更新目录」红底按钮 | 7 天 |
| ② 型号显示范围 | 显示平台：Intel 主板 / AMD 主板 / 其他（多选） | 全勾 |
| ③ 型号显示范围 | 芯片组：显示全部 / 仅显示勾选（含全选 / 全不选 / 反选） | 显示全部 |

- **保存后立即生效**，无需重启
- 配置文件 `asus_bios_checker.cfg` 写入程序目录（不可写时退回临时目录 `%TEMP%`）
- **保存目录会被记住**（v2.0.2）：选定一次即写入配置，下次启动直接沿用；换目录随时可再改
- 「恢复默认」仅复位控件（需再点「保存」才落盘）
- 过滤只影响目录树展示，**BIOS 查询对隐藏型号仍可用**（隐藏 ≠ 不可用）
- 过滤激活时，目录标题旁计数会改为「N / M 款」

## 使用方法

1. 双击 `华硕主板BIOS下载工具.exe` 启动；首次启动自动联网构建目录（约十几秒，之后秒开）
2. 左侧目录树展开芯片组后点选主板型号；或在顶部搜索行输入关键字回车定位
3. 右侧即显示该型号 BIOS 历史列表；选中版本 → 点「下载」按钮（首次会询问保存目录）
4. 下载完成后自动 SHA-256 校验，可「打开目录」查看文件
